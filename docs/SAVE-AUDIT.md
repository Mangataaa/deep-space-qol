# 卢剧情箱只读审计

`scripts/audit_lou_saves.py` 读取指定 `.es3` 存档中的库存字符串，检查库存 UUID 引用、卢玩具箱的嵌套物品、`LOU_TOY_TAG` 数量、`LOU_TOY_COUNT_INT` 和 `OPENED_TAG`。需要 Python 3，仅使用标准库。

```powershell
python scripts/audit_lou_saves.py '存档路径.es3' --backup-dir '新的备份目录'
```

脚本不改写任何存档，也不回滚日期、现金、客户进度或剧情标记。`--backup-dir` 必须指向尚不存在的目录，复制原件后核对 SHA-256。报告中的内容结局预测仅依据箱内数量和打开标记，不能代替实际游戏内的后续剧情验收。

若记录已经完整，直接保留原件，不补造物品。不应仅为绕过失败而减少要求数量或关闭剧情。缺失物品时应先核对同周目健康备份、原物品唯一编号和箱内关系，再决定是否能准确恢复；本脚本不会自动执行此类修改。

原件、备份、审计报告和离线原生数据验证样本保存在本地忽略目录，不进入 GitHub 或工坊。仅针对箱内计数和原生祖先关系的离线验证不代表完整存档载入测试。
