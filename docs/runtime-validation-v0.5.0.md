## 自动验证与发布边界

发布包重新执行 `scripts/Package.ps1 -UserRuntimeValidated`：17 套算法／原生规则检查与原生模组扫描；`inGameTestScope` 明确记录用户反馈及截图来源，`fullPlaythroughTested=false`。该标记不表示开发代理完成了自动化游戏内周目。

既有离线覆盖包括真实日排程 IL 的受控执行、枪械原生条件／槽位／权限与组合搜索、转移协调器故障恢复、悬挂几何及原生保存编码。真实 Unity 库存回调、自然过夜统计、最终交付、完整存档往返、所有分辨率与第三方模组组合仍有待更多使用反馈。
