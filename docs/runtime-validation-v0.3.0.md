# 0.3.0 定向实机验证

日期：2026-11-13。本机游戏画面显示 VERSION 100-Rev13；官方 Mod API 清单/程序集属于当前核对的 0.46 系列。目标 `Assembly-CSharp.dll` SHA-256：`725cb999d019dff1ff31bed353c7f9bb8d81a7605a15de1f80f5a3a6cf7b1d05`。

## 方法与边界

在独立槽位中载入玩家存档的字节副本，使用临时本地探针创建原生来客和原生物品，再通过实际游戏画面和鼠标点击测试生产模组。探针拒绝修改非测试槽位；不直接调用生产填价或提交方法。自然剧情、完整周目、所有分辨率、反复保存读档和其他模组兼容性没有全面覆盖。

测试画面为 2560×1440。私有日志、原始截图、探针、存档副本及个人备份不随源码或发布包上传。受控事件的 UI 结果不能表述成自然搜查剧情已经跑完。

## 存档保护

测试前备份并记录 26 个原始存档/设置文件的 SHA-256。测试结束后退出游戏，移出临时探针和测试槽位，恢复测试改动的设置；逐项核对原文件哈希。测试期临时关闭本游戏 Steam 云同步，清理并核对原件后恢复原来的开启状态。原游戏程序集未改动。

上述恢复结果属于本次本机验证记录，不是模组在用户机器上自动回滚存档的功能。模组也不补造卢物品或自动修复既有剧情。
