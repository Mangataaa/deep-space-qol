# 两阶段化学配比与批量制药（0.7.3）

一键配比入口在化学分析仪**底部中间**。打开自有液体容器的分析页后使用；本版把流程拆为过滤／蒸发前配比和处理后提纯，设备操作仍由玩家完成。

## 梦帽菇示例

1. 用搅拌机处理原料。将浆液保持在 10°C ≤ 温度 < 40°C，打开分析页，点击“一键配比”。识别原料后选择对应目标。
2. 绑定一个药剂储物页。只取该页直接摆放的药剂，不遍历全部库存或递归取箱内药。可主动选带模组页锁／箱锁的页，选择器显示锁标记。
3. 选择“① 加酒精／沉淀配比”，计算预览。先规划酒精，再按原生反应顺序处理已有蛋白、残余酸碱等。检查实际取液量、杂质、缺料、容量后再执行；计算本身不消耗药剂。
4. 梦帽菇原生最大萃取系数要求酒精至少为当前浆量的五倍，已有酒精会扣除。不纯酒精按原生比例分液换算，水和杂质一起转移。不足时仅给部分方案，不能视为达到最大萃取率。
5. **使用原生加热板实际萃取。** 梦帽菇保持 40°C ≤ 温度 < 60°C，噩梦菇为 40°C ≤ 温度 < 50°C，等浆量归零；加入常温酒精会降温。冷浆加药不等于萃取完成，模组不会替你加热或直接生成提取物。
6. 浆量归零后，用原生滤器处理残渣、蒸发器除挥发液。提前过滤可能丢失未萃取原料，蒸发器也不代替加热萃取。
7. 冷却、重新扫描，选择“② 处理后提纯”，重算残留并确认加药。沉淀与挥发液可能仍需再次过滤／蒸发；某些重金属无法靠本版加药或孔径 22 滤器去除。
8. 符合原生配方与干燥条件后，到化学制剂成型机点“批量生成”。选择机器成品区或有足够空位的指定储物页，再开始生成。

蛋白沉淀使用原生反应，无加热门槛，但药剂竞争消耗和反应顺序仍然存在，不能简单同时加等量酸碱。咖啡酒精配比以原生本轮处理量为分母，不能套用整份浆量乘五；其溶剂萃取需至少 50°C。

## 批量输出与安全边界

可制份数为当前总量除以原生配方每份体积并向下取整，无固定 16 份限制。“按当前全部含量填写数量”只填写数量，正式生成仍受原料、原生配方、干燥条件与目标空间约束。机器成品区仅 6×4 格，物品形状和已有物品会占空间；指定页满后停止，不偷偷改放其他页，不将药品塞进页内箱子或容器。

明确选择的药剂页／出药页可使用模组锁页和锁箱；此权限不扩展到自动上货和收纳。原生物理锁、插入／取出封锁、剧情／卢保护、所有权和分类限制仍然有效。

配比是有限搜索的建议，不保证任意组合的全局最优，也不保证成品达到某个纯度；终结机还会按原生规则引入自身污染。每次实际加药后重核反应，不一致则停止后续步骤。关闭配比窗会停止配比任务，已经倒入的试剂和真实反应保留。

右键／返回按最上层依次关闭选页窗、配比窗、分析页。批量任务每帧一份，可按 Esc 停止；关闭批量窗口并不等于取消正在执行的任务。

## 储物箱命名

储物窗口点击“命名”，名称显示在箱体正面中央略下。与页签名称独立保存，支持中文、长名缩小／省略；锁定不妨碍显示。具体实机验证范围见 [验证记录](runtime-validation-v0.7.3.md)。
