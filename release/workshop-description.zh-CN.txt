[h1]深空管家 / Deep Space QoL[/h1]
少点几次鼠标，把时间留给经营。《深空当铺 / Probably Stolen》原生 Mod API 模组。

[h2]0.5.0：一键改装、悬挂陈列与每日客流选项[/h2]
枪械委托面板的交付按钮左侧增加“一键改装”。根据当前委托和仓库现有散装配件，先满足全部必需条件，再争取附加奖励。跳过锁定、固定、非自有、剧情保护和机器／其他枪内零件；旧配件预留安全位置收回。缺件或空间不足会提示，完成后由你检查并手动交付，不生成零件或伪造属性。

展示柜点“悬挂”，在弹窗放入证照与灯牌，关闭后自动显示吊线、原生图案和轻微阴影，给日历留出空间。暗灯直接放到录音机左侧的右侧桌面，平时无黑框、无网格，原生效果和右键操作保留。

悬挂窗可勾选“每日逐项判定预期普通顾客”，默认关闭、次日起生效。开启后所有有效引流来源各按原概率判定一次，不再名额满了就跳过后面的来源；不足基础名额时沿用随机补足。保留冷却、保底、同名去重和特殊日规则，今天的队列不重抽，剧情来客不变。13项来源不代表每天必来13人。

[h2]鉴定省眼力，结果由你确认[/h2]
价格鉴定页的“鉴定”按钮按游戏真实计价器填价，随后由你提交；支持手臂、肉夹包、等离子燃料及官方API注册的计价器。
香烟、票券／邮票和注射器的放大检查页增加“真伪鉴定”。正品提示结果；有具体原生问题且允许对质时勾选对应问题并进入原生对质流程。自有物品只鉴定，不乱发起对质；不会改变物品真假或品质。

[h2]打开箱子，也能看清品质与风险[/h2]
荧光莓右上角显示“霉／欠／过／良／优”，悬停可看品质和单果酿造贡献；支持交易台及已经打开的箱子、背包、储物柜，未知品质显示问号。
治安部实际搜查时，违禁品红框、赃物橙框，打开容器可查看内部风险物品；普通治安部买卖不触发。不改变隐藏、上锁、热度或实际搜查结果。
改造体客户姓名后增加“【改造体】”，包括尚未扫描的真实身份，不代替扫描、举报或剧情选择。

[h2]按买家预算一键上货[/h2]
买家到店后，点击绿色“转移所有物品”左侧向上箭头，根据兴趣、已有台面商品和剩余预算选择商品，尽量提高本轮可售价值。放不下时可出售本轮后继续上货；最终出售由你确认。
遵守多样性要求，跳过固定和受保护物品；治安部顾客额外排除违禁品及赃物。普通固定柜体的未锁定库存也能取用，固定只保护柜体位置。
卢剧情箱、嵌套内容、卢玩具及原生重要物品自动保护，无需手动锁箱；台面已有剧情物品时停止上货并提示收回。

[h2]分类标签、页锁／箱锁与分帧收纳[/h2]
原生标签打印机勾选食物、水、日用品等游戏分类，支持多选。可限制手动放入类型；剧情强制放置及博士购物溢出保留原生行为。
储物窗口直接设置页锁和箱锁。锁定内容不被自动上货、自动收纳存入或取出，也不参与收纳后的自动整理；手动访问和明确点击当前页整理保留。
主库存“收纳”优先归入匹配标签页，再尝试无标签通用页；没有安全位置就留在原处。支持已核实包装和枪械整件收纳，内部配件不拆出；机器格不作为通用储物目标。
扫描和摆放搜索改为分帧，显示进度并支持Esc取消，减少大库存长时间卡顿。当前页“整理”尽量按同类成块、统一朝向紧凑排列，保留固定格、数量和物品状态；有限搜索不保证全局最优。

[h2]水源右键一键装瓶[/h2]
右键储水罐、水壶或大水桶，选择“一键装瓶”，固定水源也可使用。支持普通库存、交易台自有瓶及水瓶打印机成品区。
优先补兼容的同品质未满瓶，再装空瓶；不同水质、组分或温度不兼容时跳过。使用原生倒水，台面液体变化后刷新报价，不会自动成交。

[h2]安装与更新[/h2]
当前为0.5.0公开测试版，针对开发时核对的0.46系列游戏。订阅后按游戏模组菜单提示启用并重启，无需BepInEx。F6仅为高级设置与备用入口，主要功能都在原生按钮或右键菜单。
手动安装同ID副本会遮蔽工坊版。转用订阅版前请退出游戏，备份并将本地deep_space_qol目录移出Mods，避免同时保留两份。
[b]停用／卸载前：[/b]腾出原展示柜空间，在“悬挂”窗点“取下”并保存。跳过这一步直接不用模组读档时，原生展示柜内物品可能重叠，需要逐件移出。

通过17套算法／原生规则测试和游戏原生模组扫描。用户复测反馈“大致没问题”，新增5张0.5.0实机图：悬挂与开关、一键改装结果、真伪鉴定入口、价格填入和箱内莓果角标；保留6张历史上货、标签、整理与装瓶图及游戏像素封面。

首次使用建议保留可重新载入的存档。若提示恢复失败，请停止操作、不要继续保存，保留日志并重新载入。发布包不包含玩家存档、游戏程序集、反编译源码或临时测试工具。
