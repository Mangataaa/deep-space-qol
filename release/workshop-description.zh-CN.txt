[h1]深空管家 / Deep Space QoL[/h1]
少点几次鼠标，把时间留给经营。《深空当铺 / Probably Stolen》原生 Mod API 模组。

[h2]按买家预算一键上货[/h2]
买家到店后，点击绿色“转移所有物品”左边的向上箭头，根据顾客兴趣、已有台面商品和剩余预算选择商品，尽量提高本轮可售价值。柜台放不下时可以出售本轮后继续上货。
遵守多样性要求，跳过受保护和固定物品；治安部顾客额外排除违禁品及赃物。只帮你备货，最终出售仍由你确认。

[h2]分类标签与自动操作锁[/h2]
在原生标签打印机里勾选食物、水、日用品等真实游戏分类，支持多选。可限制手动放入的商品类型；剧情强制放置和博士购物溢出保留原生行为。
储物窗口直接提供页锁和箱锁。锁定内容不被自动上货、自动收纳存入或取出，也不参与收纳后的自动整理；手动访问和明确点击当前页整理仍保留。

[h2]分类收纳与紧凑整理[/h2]
主库存“收纳”优先放入匹配标签的储物页，再尝试无标签通用页；没有可用位置就留在原处。支持水质检测试剂盒、净水药片等已核实包装整件收纳。
各储物窗口“整理”仅处理当前页，把同物品尽量集中摆放；保留固定物品及原物品状态，不拆分或合并堆叠。机器输入输出不是通用收纳目标。

[h2]水源右键一键装瓶[/h2]
右键储水罐、水壶或大水桶，选择“一键装瓶”。固定水源也能使用，无需解除固定。支持店内普通库存、交易台自有瓶及水瓶打印机成品区的瓶子。
优先补兼容的同品质未满瓶，再装空瓶；不同水质、组分或温度不兼容的瓶子会跳过。台面装瓶后刷新原生报价，不会自动成交。

[h2]安装与入口[/h2]
订阅后按游戏模组菜单提示启用并重启。无需 BepInEx。F6 只是高级设置和备用入口，主要功能都在原生窗口按钮或右键菜单。
如已手动安装同 ID 的本模组，请退出游戏并把本地 deep_space_qol 文件夹移出 Mods，再使用工坊版，避免本地副本遮蔽工坊更新。

[h2]版本与注意事项[/h2]
当前为 0.2.1 测试版，针对开发时核对的 0.46 系列游戏。通过七套离线测试和原生模组扫描；最新修正的游戏内交互、存档往返及与其他库存／交易／液体模组的兼容性仍待确认。
上货组合和整理使用有限搜索，不保证数学上的最优结果；大量库存可能需要多次点击。原生封锁、非自有物品和锁定内容继续受保护。
首次使用建议保留可重新载入的存档。如提示恢复失败，请停止操作且不要继续保存，保留日志并重新载入。
