# 深空管家 / Deep Space QoL 0.2.3

修复一键上货可能取走卢剧情箱内容的严重问题，建议 0.2.2 用户更新后再继续含卢剧情箱的记录。

- **剧情物品自动保护**：卢的玩具箱、缴款箱和嵌套内容不参与自动上货或收纳；离开箱子的卢玩具及原生重要物品仍受保护，不依赖手动锁箱。
- **台面防护**：台面已有剧情物品时停止继续上货并提示先收回，且不计入自动预算。
- **枪械整件收纳**：支持带弹药/配件窗口的枪械，保留原枪及内部内容；不把枪内功能槽当普通储物页。
- **同类成块整理**：尝试多种行列块形与有限回溯，减少同类散落、朝向不一致及空隙。只有完整且更好的候选才应用，不保证全局最优。
- **收纳后最终整理**：为腾空间预先整理过的页，在新增物品后会再次尝试整理，页数不重复计算。

通过七套离线测试：储物策略 79、整理 549、上货 8 个确定场景及 120 个固定种子场景、液体策略 6027、真实原生买家 42、储物目录与生产收纳筛选 388、原生装瓶访问 103。生产构建零警告、零错误；原生模组扫描通过。另做五页真实物品形状的只读离线排布检查。

0.2.3 的游戏内操作、后续剧情和完整存档往返仍待实机复测。保留此前用户在 0.2.2 实机确认的打印机装瓶修复及六张标注版本的截图。

本版不会自动改写玩家存档或补造物品。仓库附有只读卢箱审计与可选备份脚本；个人存档、审计样本和备份不随发布包或源码上传。

关闭游戏后更新本地安装，或在 Steam 工坊更新并启用本模组。若本地 `Mods/deep_space_qol` 已存在，它会遮蔽同 ID 的工坊版本，请确认实际加载版本为 0.2.3。
