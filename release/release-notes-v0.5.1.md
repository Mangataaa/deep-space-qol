# 深空管家 / Deep Space QoL 0.5.1

## 本次更新

- **违禁品买家与超科技走私犯免冷却**：默认忽略两项夜间服务的 3／5 天等待，现有存档剩余冷却也适用。仍需解锁、夜间勾选并支付原费用；不影响其他服务或普通顾客。游戏设置可关闭恢复原版判断，不改写存档冷却字段，不重抽今天的来客。
- **水瓶打印机打印水壶**：原控制列增加“打印水壶（6L）”，生成游戏自带 6L 空水壶。累计 9 次升级解锁原版大瓶后可用，耗电 33，使用原成品区；缺电、未解锁或放不下时不扣电。保留原三种瓶配方，新空壶可使用已有一键装瓶加水。

保留 0.5.0 的一键改装、悬挂陈列、每日顾客逐项概率、鉴定、箱内提示、卢剧情保护、分类收纳及右键装瓶。

## 展示与验证

通过 **19 套自动回归和游戏原生模组扫描**。用户复测确认后发布；新截图显示原生水壶、打印按钮及“6L 空水壶，消耗 33 电量”的成功提示。新图追加到原工坊条目，保留封面和原有 11 张图。

连续多日服务到访、全部电源、前后电量差和完整保存重载未逐项记录。具体范围见源码 `docs/runtime-validation-v0.5.1.md`，不将单张截图表述为完整周目验收。

## 更新

退出游戏后更新。工坊订阅沿用原条目；手动安装请解压 `DeepSpaceQoL-0.5.1.zip`，将其中 `deep_space_qol` 放入游戏 `Mods`。同 ID 手动副本会遮蔽工坊版，避免同时保留两份。

停用／卸载前请腾出原展示柜空间，在“悬挂”管理窗点“取下”并保存。F6 继续为备用入口。
