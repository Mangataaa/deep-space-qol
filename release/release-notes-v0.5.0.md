# 深空管家 / Deep Space QoL 0.5.0

把更多操作放回原生窗口：一键改装、悬挂陈列、鉴定和箱内品质提示。

## 本次更新

- **一键改装**：枪械委托的交付按钮左侧增加入口，按当前委托与仓库现有配件匹配完整必需条件，再争取附加奖励。跳过锁定、固定、非自有、剧情保护和机器／其他枪内的配件；旧件预留位置收回，完成后由玩家手动交付。
- **证照与灯牌悬挂**：展示柜点“悬挂”打开管理窗，放入后关闭，自动展示原生图案、吊线与轻微阴影；左侧避开日历。暗灯放在右侧无框桌面区域，保留原生效果和操作。
- **预期普通顾客逐项判定**：悬挂窗口新增默认关闭的勾选。开启后下一次每日排程让所有有效来源分别按原概率判定，不再达到基础名额就跳过后面的来源；不足时沿用随机补足。保留冷却、保底、去重、特殊日及剧情规则，不重抽今天，也不保证 13 项来源每天都来 13 人。
- **真伪鉴定**：香烟、票券／邮票、注射器放大检查页增加按钮。正品提示结果；具体原生问题且允许对质时进入原生对质流程。
- **箱内提示修复**：打开箱子、背包和储物柜时，莓果角标与搜查风险高亮能覆盖已打开的浮动窗口。
- **分帧收纳**：扫描与摆放搜索按帧执行，显示进度，减少大库存收纳时的长时间卡顿；可按 Esc 取消。

保留按预算上货、分类多选与页／箱锁、固定柜体库存取用、卢剧情保护、同类紧凑整理、鉴定填价、改造体姓名及右键装瓶。

## 更新方法

关闭游戏后更新。工坊沿用原条目，订阅者由 Steam 获取更新；手动安装请解压 `DeepSpaceQoL-0.5.0.zip`，将其中 `deep_space_qol` 目录放到游戏 `Mods` 下，保留旧版备份。

同 ID 的手动副本会遮蔽工坊版，避免同时保留两份。停用／卸载前请腾出原展示柜空间，在“悬挂”管理窗点“取下”并保存。F6 继续作为备用入口。

ZIP SHA-256：`236dec6a64cdf507d6ffbb2dd13ed857d833cc0f64c541f3112e7a210df40b41`。附件另附同名 `.sha256` 文件；压缩包内有逐文件 `SHA256SUMS.txt`。发布 DLL 与用户复测的 0.5.0 二进制一致。
