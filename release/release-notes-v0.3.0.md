# 深空管家 / Deep Space QoL 0.3.0

这次增加四项日常操作提示，主要入口仍在游戏原生界面，无需按 F6。

- **鉴定填价**：价格鉴定页点击“鉴定”，按原生规则填入价格，再由你点击原生提交。覆盖三类现有价格委托和官方 API 注册的计价器；没有价格框的检查页不添加虚构价格。
- **搜查风险高亮**：搜查期间违禁品红框、赃物橙框，容器内部风险也会提示。普通治安部买卖不触发，不改变隐藏、锁、热度或搜查判定。
- **改造体姓名**：对话与交易面板姓名后显示“【改造体】”，包括尚未扫描的真实改造体；不替你执行扫描或任务。
- **莓果品质**：角标区分“霉 / 欠 / 过 / 良 / 优”，悬停和放大检查页显示详情；不改变品质或酿造结果。

通过十一套离线测试与原生模组扫描。在独立存档副本里完成定向 UI 实测，包括三类鉴定填价、一次手动提交、五种莓果角标与悬停、风险高亮及清除、改造体与普通来客切换。另重测一键上货 4 件，卢箱内容保持不变。

界面实测使用受控原生来客和物品，不代表自然剧情、完整周目、所有分辨率或其他模组兼容性已全面验证。个人存档、临时测试探针和私人日志不随本版发布；保留 0.2.3 的剧情保护与整理/收纳修复。

关闭游戏后更新本地安装，或让 Steam 工坊更新并启用。本地 `Mods/deep_space_qol` 会优先于同 ID 工坊副本，请在游戏模组菜单确认实际版本为 0.3.0。原来的六张工坊展示图和封面保留。
