# 深空管家 / Deep Space QoL 0.2.1

《深空当铺 / Probably Stolen》原生 Mod API 模组，适配开发时核对的 0.46 系列游戏。

## 安装

1. 下载 `DeepSpaceQoL-0.2.1.zip` 并解压。
2. 关闭游戏，把 `deep_space_qol` 文件夹放入游戏安装目录的 `Mods` 文件夹。
3. 启动游戏，在模组菜单启用“深空管家 / Deep Space QoL”，按提示重启。

更新前请保留旧版与可重新载入的存档。无需 BepInEx，不覆盖游戏程序集。

## 功能入口

- 买家到店后，绿色转移按钮左侧的向上箭头按需求及预算备货，最终交易由玩家确认。
- 储物窗口提供整理、标签、页锁和箱锁；标签打印机支持真实游戏分类多选。
- 主库存“收纳”按分类归置；水源右键“一键装瓶”补空瓶和兼容的同品质未满瓶。
- F6 是备用高级面板，日常操作不依赖快捷键。

## 本次修复

- 修复水质检测试剂盒、净水药片等便携包装匹配标签却不收纳。
- 锁定页不再接收自动收纳，也不自动取出或自动整理。
- 固定储水罐支持原地装瓶；交易台自有瓶和水瓶打印机成品瓶加入装瓶范围。
- 台面装瓶后刷新报价，保留买家兴趣、多样性和治安部安全检查。
