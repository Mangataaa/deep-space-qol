# 深空管家 / Deep Space QoL 0.3.1

修复固定、未锁定储物容器中的商品未参与一键上货的问题。

游戏原生普通储物柜和背包也有“重要物品”标签，此前模组把该标签误当成整个容器内容的剧情保护。现在对已经核对身份和窗口结构的普通自有储物容器，固定仅保护柜体位置，未锁定内容正常参与上货；分类收纳也可识别这些储物页。

容器本体仍不可被自动出售或搬走。商品本身固定、页锁、箱锁、祖先锁、原生封锁和卢的剧情物品继续受保护；未知的重要容器仍然跳过。

通过十一套离线回归和原生模组扫描，储物测试已加入真实的原生重要标签以及固定／非固定、普通箱包、三页柜、嵌套固定背包与锁定反例。此版本尚未进行新的游戏内操作复测；此前 0.3.0 定向实机结果不作为本修复的实机验收。安装不改动游戏程序集或存档。

关闭游戏后更新，启动时确认模组版本为 0.3.1。沿用原工坊条目、封面和六张历史展示图。
